# W8D4 Documentation, Testing & Code Review

## 1. Project Overview

This project implements a simple document review workflow using LangGraph.

The workflow accepts a document as input, analyzes the document, calculates its word count, and generates a basic review based on the document length.

The purpose of this project is to demonstrate clean implementation, automated testing, documentation, and code review practices for an AI/ML application.

---

## 2. Technology Stack

- Python 3.12.5
- LangGraph 1.2.11
- pytest 9.1.1
