# W8D2 - RAG Evaluation with Ragas Framework

This project implements a Retrieval-Augmented Generation (RAG) pipeline
using LangChain and ChromaDB and evaluates the system using the Ragas framework.

## Objectives

1. Build a RAG pipeline using LangChain and ChromaDB.
2. Generate 10 question-answer pairs from the dataset.
3. Evaluate the RAG system using Ragas.
4. Measure faithfulness, answer relevancy, context precision, and context recall.
5. Optimise the lowest-scoring metric.
6. Re-evaluate and compare the results before and after optimisation.

## Technology Stack

- Python
- LangChain
- ChromaDB
- Ollama
- Ragas
- qwen2.5:3b
- nomic-embed-text
